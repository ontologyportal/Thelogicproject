The Logic Project

Lowering the gate to formal knowledge contribution

A wizard that lets non-ontologists contribute to the Suggested Upper Merged Ontology (SUMO). The LLM handles search and Socratic dialogue. SigmaKEE handles syntax, type discipline, and theorem proving. The wizard is the seam between them.
